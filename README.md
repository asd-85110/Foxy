# Foxy游戏项目
![logo](logo.png)
## 简介
这是我的一个游戏项目,用于训练我的游戏开发能力,同时提供游戏.
## 下载
你可以选择下载预编译(Windows,推荐)  
或者源码编译(Linux或者Windows)  
Mac OS暂时无法处理
## 编译
在编译之前，请确保做好一下准备:  
1. 获取源码  
    ```bash
    #使用git进行克隆
    git clone https://github.com/asd-85110/Foxy.git
    ```
2. 编译
    ```bash
    #编译
    ./autobuild #自动构建脚本,也可以手动构建
    ```
    注意:请确保使用GCC(MinGW-w64),不然所有库都要重新编译.项目可能引进的C++库需要重新编译.请确保安装了CMake,最好再安装Ninja构建器.
